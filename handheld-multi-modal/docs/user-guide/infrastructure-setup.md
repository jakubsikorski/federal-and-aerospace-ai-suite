# Infrastructure Setup

There are 2 ways to prepare the required infrastructure:

1. Install [Edge Pack](https://docs.openedgeplatform.intel.com/dev/platform-software/edge-pack/index.html) on Canonical's Ubuntu - recommended for demo or development deployments. This way is covered in [Installation on Ubuntu](./infrastructure/installation-on-ubuntu.md).
2. Create customized ISO image that will contain all dependencies from [Edge Pack](https://docs.openedgeplatform.intel.com/dev/platform-software/edge-pack/index.html) and can be easily installed across multiple computers. Steps are documented in [Customized Image](./infrastructure/customized-image.md).

Edge Pack packages and how they could be used are documented in [Infrastructure capabilities](./infrastructure/platform-capabilities.md).

If you have issues, take a look at [Troubleshooting guide](./infrastructure/platform-capabilities.md).
