How this application is built

Built on Intel Open Edge Platform release-2026.2.0 microservices, run unmodified from their published images and used through their own APIs.

Back to app
Follow a flow:
RTSP video WebRTC (WHIP / WHEP) TURN relay MQTT events Evidence images (shared volume) HTTPS / REST / SSE
Intel Open Edge Platform microservice — blue box, endpoints called listed inside Open-source infrastructure Application (custom code)

Where each model runs

NPU

  • YOLO26s INT8 object detection (default pipeline)

GPU

  • Intel/neural-chat-7b-v3-3 language model
  • whisper-medium speech to text
  • Video decode and encode (VA-API) in the NPU/GPU pipelines

CPU

  • gvatrack object tracking
  • Embeddings and reranker for document retrieval
  • SpeechT5 text to speech (GPU switch available)
  • Application Backend, brokers and relays

These are the configured defaults. The Models & devices strip in the app shows what each service reports at run time. The Backend is never in the video path, does not crop images and does not reconfigure pipelines while they run; it owns business rules, history (SQLite), speech arbitration and telemetry aggregation.

Open Edge Platform APIs used

Every call below goes to a stock Open Edge Platform endpoint; there are no custom model servers or patched services. Source links point to the pinned edge-ai-libraries commit; documentation: docs.openedgeplatform.intel.com.
